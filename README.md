# 💰 Casa Clara

### 🧾 Controle de Gastos da Família Lopes

Um sistema web simples e intuitivo para controle de gastos familiares, permitindo registrar despesas, acompanhar o total mensal e entender melhor para onde o dinheiro está indo.

---

## 📌 Sobre

O **Casa Clara** foi desenvolvido para ajudar a família Lopes a organizar suas finanças sem a necessidade de planilhas complicadas.

Através de uma interface limpa e prática, é possível adicionar gastos, categorizar e visualizar resumos financeiros em tempo real.
